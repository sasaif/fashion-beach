## 3. Uncertainties (stated plainly)
- **VRM PL "derivative" scope**: we treat our clothes and face textures as derivatives of the pixiv model (they are geometrically derived from it), so they inherit VRM PL 1.0. That is permissive for this game, but it means those GLB/PNG files can't be published as CC0/MIT assets on their own.
- **Model provenance**: the VRM was taken from the three-vrm GitHub examples (the repo code is MIT, the model is under its own VRM license per the repo README and the file meta). The meta inside the file is the authoritative statement we rely on.
- **Quaternius CC0**: verified from the License.txt inside the official downloads (free "Standard" tier) and the itch.io page at download time; no attribution is required (credit kept anyway in ASSETS_LICENSES.md).
- **Emoji/system fonts**: shown on the user's device by the OS, not redistributed by us; if the game ever ships a font or emoji set, its license must be added here.
- This is an engineering audit, not legal advice.
